Antes de instalar

Preguntas frecuentes

¿Necesito saber programar o instalar Python?

No. El instalador de Windows trae todo embebido, ffmpeg incluido. Se instala como cualquier programa y se abre desde el menú inicio.

¿Mis videos se suben a algún servidor?

Nunca. Todo el procesamiento corre en tu propia computadora. PixelClean no tiene conexión a internet ni la necesita.

¿Funciona con cámaras que no sean la Sony A7III?

Sí. Se probó primero sobre A7III porque fue donde apareció el defecto original, pero el pincel de máscara y ambos motores de reparación funcionan con cualquier clip donde puedas fotografiar el punto dañado, sin importar de qué color sea el píxel.

¿Qué pasa si cancelo a mitad de un lote?

El clip que se estaba procesando en ese momento se descarta junto con su archivo parcial; los clips ya terminados quedan guardados.

¿Cuál motor debería usar?

Empezá con Blur para revisar rápido que la máscara esté bien ubicada en todo el lote, y pasá a OpenCV Inpainting para la exportación final.
